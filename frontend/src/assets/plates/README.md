# Final plate artwork

Drop plate images here, named after the dish (e.g. `Butter Naan.jpg`) or an art key
(e.g. `tandoori-chicken.png`). Accepted formats: `.png`, `.jpg`, `.jpeg`, `.webp`, `.avif`.
Square images (1024x1024 or larger) look best. See `docs/design/ART-BRIEF.md`.
They are picked up automatically; no code changes are needed.
